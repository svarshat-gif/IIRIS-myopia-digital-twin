# Data card

Generated by build_training_table.py from checksum-verified files.

## Used for training and open-record seeding

[Zenodo DIMS 36-month dataset](https://zenodo.org/records/18166476), [original workbook](https://zenodo.org/records/18166476/files/DataSet.xlsx?download=1), CC BY 4.0 (verified in the repository API metadata). Sheet1 has 20 subject rows and 139 columns. Px_ID links seven scheduled measurements: baseline, 3, 6, 9, 12, 24 and 36 months. SER_* and AL_* are used, together with baseline Age. Gender is B/G without a supplied codebook, so normalized sex stays missing. Peripheral-refraction fields and the repeated-position poly sheet are not independent subjects and are excluded. The workbook is retained unmodified with attribution in backend/data/open/SOURCES.md.

Units: SER is interpreted as D (negative myopic) and AL as mm from the field names, study context and observed ranges. No independent units or eye-selection codebook was supplied; this remains a limitation. No unit conversions or invented calendar dates/ages/exposures are used.

## Inspected metadata only; not used

- [Dryad three-year cohort](https://doi.org/10.5061/dryad.d4mb3pn): 452 children per the study metadata, CC0 per repository metadata. Download returned HTML; authenticated API download returned 401. Workbook headers, patient/eye linkage and missingness are unverified. The adapter fails explicitly pending inspection of Data3.xlsx.
- [Dryad Shanghai 2014/2018](https://doi.org/10.5061/dryad.c2fqz615c): CC0 per repository metadata; independently sampled schools in two years are described. Download failed verification. No longitudinal linkage is established, so it is excluded from training and validation. Lifestyle questionnaires are mentioned in the abstract, but no workbook variables have been verified or used.
